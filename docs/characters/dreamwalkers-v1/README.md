# 夜を渡る16人 — 人間版キャラクター設定集

添付の16タイプ一覧を参考に、髪型・普段着・表情・モチーフを引き継ぎ、ユメタンの深い夜色に合わせて内蔵画像生成ツールで1人ずつ制作しました。全員、架空の成人として設定しています。

## アプリでの切り替え

初期表示は人間版です。**設定 → 表示キャラクター → 人間キャラクター / 動物キャラクター → 保存** でいつでも切り替えられます。選択は端末内に保存され、再起動後も維持します。診断タイプ、アンケート回答、夢・日記、睡眠レベルは変更しません。初回オンライン読み込み完了後は両シリーズともオフラインで使えます。

ローズ（悪夢）・藤色（予知）・ミント（明晰）・琥珀（反復）の光で4グループを区別。落ち着いたアニメ調の線と陰影、黒やグレーの普段着で統一しました。添付の文字やラベルは画像に焼き込まず、名前・役割・紹介・ひとことは4言語でアプリに表示します。1タイプにつき基本画像1枚で、5段階は既存の星表示を使います。

キャラクターは夢の表現を楽しむための創作です。ユーザーの人格、健康状態、未来を断定するものではありません。

## 16人の設定

### 01. レン / Ren — 振り返る夜の走者

- タイプ：悪夢タイプ / 追跡系（`chase`）
- 参考画像からの要素：添付①：黒髪、黒いパーカー、振り返る動き、緊張した表情。ローズの光跡。
- 設定：黒いパーカーで夜道を走る青年。追われる夢の緊張を感じながらも、自分の進む方向を探している。
- ひとこと：「次の一歩は、自分で選ぼう。」
- [原本](../../../assets/characters/dreamwalkers-v1/originals/chase.png) / [表示用](../../../public/assets/characters/dreamwalkers-v1/chase.webp)

## 更新方法

4言語の設定の正本は `public/assets/characters/dreamwalkers-v1/catalog.js`。シリーズの初期値と一覧は `public/core/characters.js` にあります。画像更新時は新しいバージョンのフォルダを作り、参照とService Workerキャッシュを更新してください。配信用WebPの再生成は `npm run characters:build -- human`。動物版の原本・設定・配信用画像は今回変更していません。
