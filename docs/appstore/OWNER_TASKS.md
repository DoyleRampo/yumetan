コード側の対応は `develop` に入っています。決定済み: 通報・ブロックは削除のまま（Notes で説明）、事業者名「ユメタン運営」、連絡先 080-8978-7788、対象年齢 13 歳以上（App Store の年齢制限指定は別途 4+ で可）。以下は **Apple / Firebase の管理画面や実機が必要で、本人にしかできない作業** です。上から順に進めてください。所要時間の目安は合計 3〜4 時間です。

## 1. サーバーとアプリを最新にする

1. Fly.io / Render の管理画面で `develop` の最新コミットをデプロイする（自動デプロイ設定なら push 済みで完了）。
2. ブラウザで次の 2 つが開くことを確認する（`<サーバー>` は `API_URL` と同じホスト）:
   - `https://<サーバー>/legal/privacy.html?lang=ja`
   - `https://<サーバー>/legal/terms.html?lang=en`
3. GitHub → Actions → 「iOS TestFlight」が `develop` の push で成功していることを確認する（失敗していたらログの赤い行を送ってください）。
4. iPhone の TestFlight アプリで新しいビルドをインストールする。

## 2. Firebase（10 分）

1. https://console.firebase.google.com → プロジェクト `yumetan-a31f0` → **Authentication → Sign-in method** → 「新しいプロバイダを追加」→ **メール / パスワード** → 有効にして保存。
2. **Firestore のインデックス**を反映する。PC のターミナルでリポジトリ直下に移動して:

   ```sh
   npx firebase-tools login
   npx firebase-tools deploy --project yumetan-a31f0 --only firestore:indexes
   ```

   未反映でもアカウント削除は失敗しない（「他人の投稿に付けたスタンプ」は投稿を順に見て消す）が、反映すると横断検索で一度に見つかり速い。
3. Google Cloud Console → IAM で、サーバーが使うサービスアカウント（`FIREBASE_SERVICE_ACCOUNT_JSON` の `client_email`）に **Firebase Admin SDK Administrator Service Agent** ロールがあることを確認する（Auth ユーザー削除に必要）。

## 3. デモアカウントを用意する（20 分）

審査員は LINE や 2 段階認証付き Google を使えないので、**メール / パスワード**のアカウントを使う。ID とパスワードは `REVIEW_NOTES.md` の先頭に記載（`yumetan-review@gmail.com`）。

1. TestFlight 版アプリを起動 → 導入 → 「メールでログイン」→ **新規登録** でこのメールとパスワードのアカウントを作る（作成済みならログイン）。
2. 呼び名を入れて 24 問の診断まで進め、夢を 1 件記録しておく。
3. Firebase Console → **Authentication → Users** でこのアカウントの **UID** をコピー。
4. Firebase Console → **Firestore Database** → コレクション `memberships` → 「ドキュメントを追加」→ ドキュメント ID に UID を貼り、フィールドを追加:

   | フィールド | 型 | 値 |
   | --- | --- | --- |
   | plan | string | standard |
   | status | string | active |
   | paidUntil | number | 4102444800000 |
   | cycle | string | yearly |
   | source | string | manual |

   これで購入なしに他人の投稿の全文・スタンプ・AI 読み解きが使える（2100 年まで有効）。購入フローはスターターへの「登録する」（プラン切替）で Sandbox 購入を試せる。
5. **「みんなの夢」はその日に公開された夢だけを表示する**ので、提出する日（と審査中の毎日）にこのアカウントか自分のアカウントで夢を 1〜2 件公開しておく。Notes には「空なら自分の夢を公開すればすぐ表示される」と書いてある。

## 4. App Store Connect（30 分）

https://appstoreconnect.apple.com → マイ App → ユメタン。

### 4-1. App 情報（左メニュー「App 情報」）

- **プライバシーポリシー URL**: `https://<サーバー>/legal/privacy.html`
- **使用許諾契約（EULA）**: 「カスタム使用許諾契約」に `https://<サーバー>/legal/terms.html?lang=en` の英語本文をコピーして貼る（空欄なら Apple 標準 EULA が適用され、アプリ内の「利用規約」リンクは自前ページを開く。どちらでも可）。
- **年齢制限指定**: 「編集」→ 質問に答える。UGC（ユーザー生成コンテンツ）の項目は「はい」。結果が 4+ / 9+ / 12+ のどれになっても問題ない。

### 4-2. App のプライバシー（左メニュー「App のプライバシー」）

「データの収集を開始」→ 収集するデータ:

| データ | 用途 | ユーザーに関連付け | トラッキング |
| --- | --- | --- | --- |
| 連絡先情報 → メールアドレス | アプリの機能 | はい | いいえ |
| 連絡先情報 → 氏名（ソーシャルログインの表示名が Firebase Auth に入る） | アプリの機能 | はい | いいえ |
| ユーザコンテンツ → 写真またはビデオ、その他のユーザコンテンツ | アプリの機能 | はい | いいえ |
| 健康とフィットネス → 健康 | アプリの機能 | はい | いいえ |
| ID → ユーザ ID | アプリの機能 | はい | いいえ |
| ID → デバイス ID（RevenueCat SDK が IDFV を送信） | アプリの機能 | はい | いいえ |
| 購入 → 購入履歴 | アプリの機能 | はい | いいえ |
| 使用状況データ → その他の使用状況データ（プラン上限の回数管理） | アプリの機能のみ（アナリティクスは付けない） | はい | いいえ |

位置情報・連絡先・閲覧/検索履歴・診断データ・オーディオデータは収集していないので申告しない。

## 5. 実機で画面録画（40 分）

### 5-1. 準備

1. **Sandbox テスター**でサインイン: iPhone の 設定 → App Store → 一番下「サンドボックスアカウント」→ 4-4 で作ったテスターの Apple ID。ここに項目が出ない場合は、TestFlight 版を一度起動してから設定を開き直す。
2. **デモアカウントの下準備**: `yumetan-review@gmail.com` でログインし、その日のうちに夢を 1〜2 件公開しておく（フィードは当日公開分だけを表示）。終わったら設定 → ログアウト。
3. **録画で使う使い捨てアカウント**を決める: `yumetan-review+rec1@gmail.com`（Gmail の `+` 付きアドレスは同じ受信箱に届き、Firebase では別アカウント扱い）。録画の最後にこれを削除するので、デモアカウント本体は無傷で残る。
4. 通知が映らないように「おやすみモード（集中モード）」をオン。画面の自動ロックを「なし」に（設定 → 画面表示と明るさ → 自動ロック）。
5. コントロールセンターに「画面収録」を追加: 設定 → コントロールセンター → 「画面収録」の＋。
6. 初回画面の言語切替で **English** にしておくと審査員に伝わりやすい（日本語のままでも可）。

### 5-2. 録画の操作（1 本、5〜7 分）

画面右上から下へスワイプ → 画面収録ボタン（◉）をタップ → 3 秒後に開始。ステータスバーが赤くなる。以下を順に操作する。

1. ホーム画面でユメタンのアイコンをタップして起動。
2. 導入 → 「メールでログイン / Sign in with email」→ **新規登録 / Create account** → `yumetan-review+rec1@gmail.com` と任意のパスワード（12 文字以上）→ 登録。
3. 呼び名と年代を入力 → 24 問に答える → キャラクターの結果 → はじめる。
4. 下タブ「夢を記録 / Dream」→ 本文を 2〜3 行入力 → 「この夢を診断 / Read this dream」→ 結果が出たら「この夢をみんなの夢に公開する / Share this dream in the dream feed」に**チェック** → 保存。
5. 設定（右上の歯車）→ 「プランを見る / See plans」→ スターターの「詳細 / Details」→ 画面を下へ → **「利用規約 ↗ / Terms of Use ↗」をタップ**（Safari が開く。2〜3 秒映してからアプリに戻る）→ **「プライバシーポリシー ↗ / Privacy Policy ↗」をタップ**（同様に戻る）→ プラン名・期間・価格の枠の下にある **「スターターに登録する / Subscribe to Starter」** → App Store の購入シート（Sandbox 環境と表示される）→ 「購読 / Subscribe」→ 完了 → 画面に「現在のプラン」と出るまで待つ。
6. 下タブ「みんなの夢 / Dream feed」→ 手順 5-1-2 で公開した投稿を開く → スタンプを 1 つ付ける。
7. 「夢を記録」で手順 4 の夢を開く → チェックを外す → 保存（非公開に戻る）。
8. 設定 → アカウント → **「アカウントを削除 / Delete account」** → 確認ダイアログで OK → 初回画面に戻る。
9. 赤いステータスバーをタップ → 「停止」。動画は写真アプリに保存される。

失敗したら途中で止めて最初から撮り直してよい（使い捨てアカウントは削除済みなので、`+rec2` など別のアドレスで作り直す）。

### 5-3. 動画の確認と圧縮

- 写真アプリで再生し、起動から削除完了まで映っていることを確認する。
- ファイルは通常 5〜7 分で 100〜300 MB 程度。App Store Connect にアップロードできない大きさなら、Mac の iMovie または QuickTime（ファイル → 書き出す → 1080p）で書き出す。
- Mac へは AirDrop で送る（写真アプリ → 共有 → AirDrop）。

## 6. 返信と再提出（15 分）

App Store Connect は Mac（または iPad）のブラウザで開く。

1. https://appstoreconnect.apple.com → マイ App → ユメタン → 左メニューの **「App Review」**（赤い！が付いている）を開く。却下メッセージのスレッドが表示される。
2. 一番下の **「返信」** 欄に `REVIEW_NOTES.md` の `---` 〜 `---` の本文を貼る（`[iPhone model]` `[iOS version]` を置き換える）。
3. 返信欄の **クリップ（添付）アイコン** → 5-3 の動画ファイルを選ぶ → アップロード完了（進捗バーが消える）を待つ → **送信**。
   - 添付が失敗する（サイズ上限）場合は、動画を Google Drive か YouTube（限定公開）に置き、そのリンクを返信本文の 1 番の直後に書く。
4. 左メニュー「App 情報」→ 「App Review に関する情報」（バージョンページの下部）にも同じ本文を **「メモ」** に貼り、**「添付ファイル」** にも同じ動画をアップロードする（今後の提出でも参照されるため）。

6. 右上 **「保存」** → **「審査へ提出」**。ステータスが「審査待ち」になれば完了。
