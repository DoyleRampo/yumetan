# 睡眠の質と夢の対応知識（ユメタン用）

この文書は、夢の内容・朝の自己申告・前日の生活記録から「睡眠の質」を推定し、レベル（1〜5）と寝る前のアドバイスを出すための知識です。
端末内のルールエンジン（`public/engine/sleep.js`）はこの知識を数値ルールに落として使い、AI（Claude）を使うときは system prompt として丸ごと渡します。
医療的な診断ではなく、「眠りの手応え」を本人が振り返るための目安です。

---

## 1. 睡眠の質とは何か（ここでの定義）

睡眠研究で「主観的睡眠の質」を測る標準的な尺度（ピッツバーグ睡眠質問票 PSQI、不眠重症度指数 ISI、エプワース眠気尺度 ESS 等）は、概ね次の要素で構成されている。

| 要素 | 良い状態 | 悪い状態 |
|---|---|---|
| 寝つき（入眠潜時） | 20分以内に眠れる | 30分以上かかる／布団で何度も寝返り |
| 中途覚醒 | 夜中に起きない、または1回で再入眠できる | 2回以上／起きたあと眠れない |
| 早朝覚醒 | 予定の時刻まで眠れる | 予定より1時間以上早く目覚めて眠れない |
| 睡眠時間 | 成人 7〜9時間（個人差あり） | 6時間未満が続く／9〜10時間超が続く |
| 睡眠効率 | 布団にいる時間の85%以上眠っている | 85%未満 |
| 目覚めの感覚（睡眠慣性） | 15〜30分で頭が晴れる | 1時間以上だるい／二度寝したくなる |
| 日中の機能 | 眠気なく過ごせる | 昼間に強い眠気・集中できない |

ユメタンでは、これを **スコア 0〜100** にまとめ、次の5段階に分ける。

| レベル | スコア | 意味 |
|---|---|---|
| 5 | 80〜100 | 理想的。深く連続した眠りで、目覚めが軽い |
| 4 | 65〜79 | 良好。ほぼ安定しており、小さな乱れはある |
| 3 | 50〜64 | ふつう。日によってばらつく |
| 2 | 35〜49 | 浅め。寝つき・中途覚醒・目覚めのどれかに問題 |
| 1 | 0〜34 | かなり浅い。複数の問題が重なっている |

キャラクターの **レベル** は直近7件の記録の加重平均（新しいほど重い）で決める。1件だけの悪い夜で下がりすぎないようにするため。

## 2. 夢の内容から読み取れる睡眠の質（重要）

夢そのものは主観的睡眠の質の「間接指標」だが、次の対応は研究的にも比較的一貫している。

### 2.1 睡眠が浅い・乱れているサイン（減点）

| 夢の特徴 | 根拠 | 目安 |
|---|---|---|
| **悪夢**（恐怖で目が覚める、うなされる） | 悪夢は睡眠分断・中途覚醒と強く相関する。悪夢の頻度が高い人ほど PSQI が悪い。不眠・PTSD・ストレス期に増える | -12 |
| **金縛り（睡眠麻痺）・体が動かない夢** | 睡眠麻痺は睡眠不足・不規則な睡眠・仰向け寝・時差・ナルコレプシーで増える。REM 睡眠の断片化のサイン | -10 |
| **強い負の感情 + 高い感情強度** | REM 睡眠中の扁桃体活動が高い状態。ストレス負荷・情動処理が追いついていない | -8 |
| **繰り返す嫌な夢**（同じ悪夢） | 未処理のストレス。悪夢障害の基準の一つ | -6 |
| **夢の中でも疲れている・だるい** | 身体的疲労が夢内容に反映。回復睡眠が不足 | -6 |
| **水・トイレ・溺れる・尿意の夢** | 膀胱の充満・口渇など身体感覚の混入。覚醒直前の浅い睡眠で起きやすい | -4 |
| **痛み・病気・怪我の夢** | 身体の不調（痛み、発熱、寝具の不適合）が夢に混入 | -4 |
| **途中で飛び起きて終わる夢** | 覚醒反応。交感神経の亢進 | -4 |
| **夢を鮮明に大量に覚えている**（毎晩複数） | 夢想起率は中途覚醒の回数と相関する。REM 直後に覚醒すると夢を覚える。「よく覚えている＝眠りが良い」ではない | 0（他の要因と合わせて判断） |

### 2.2 睡眠が整っているサイン（加点）

| 夢の特徴 | 根拠 | 目安 |
|---|---|---|
| **心地よい・楽しい夢**、穏やかな感情 | 良好な気分・低ストレス期に増える。REM 睡眠の情動調整が機能している | +6 |
| **明晰夢**（夢だと気づく） | 高い自己認識。ただし明晰夢は覚醒閾値が低い REM でも起きるため、加点は小さく | +2 |
| **夢を覚えていない・断片だけ** | 深い睡眠（徐波睡眠）が多く中途覚醒が少ない可能性。ただし睡眠不足による REM 減少でも同じ結果になる | 0 |
| **夢の中で対処できた・逃げ切れた** | 情動処理が完了しているサイン | +2（分析側の outcome=good） |

### 2.3 REM 睡眠と夢の関係（背景知識）

- 夢は主に REM 睡眠で見る（ノンレム中にも思考のような夢はある）。REM は夜の後半に長くなるため、朝方の夢が最も長く鮮明。
- **アルコール**は REM を前半で抑制し、後半に「REM リバウンド」を起こす → 後半に激しい夢・悪夢・中途覚醒が増える。
- **睡眠不足**が続いたあとの夜も REM リバウンドで夢が激しくなる。
- **一部の薬**（β遮断薬、抗うつ薬の中止、ニコチンパッチ等）は鮮明な夢や悪夢を増やす。医師に相談すべきケース。
- **発熱**や**寝室の高温**は夢を奇妙に、悪夢を増やす。
- **睡眠麻痺**は REM 中の筋弛緩が覚醒後も残る現象。仰向け寝、睡眠不足、不規則な睡眠、ストレスで増える。人口の 8% 程度が生涯に経験。

| 睡眠時間 | 点 | 補足 |
|---|---|---|
| 5時間未満 | -12 | 慢性的な短時間睡眠。悪夢・金縛り・情動不安定の主因 |
| 5〜6時間 | -5 | |
| 6〜7時間 | +3 | |

## 5. 前日の生活（日記）から読み取る要因

夢の診断は **前日の日記** を参照する。日記のキーワード照合で次を拾う。

| 要因 | 点 | 根拠 |
|---|---|---|
| カフェイン（コーヒー・エナジードリンク・紅茶） | -4 | 半減期 5〜6時間。午後の摂取は入眠を遅らせ深睡眠を減らす |
| アルコール | -6 | 入眠は早まるが後半の睡眠が分断、REM リバウンドで夢が激しくなる |
| 夜更かし・寝る前のスマホ／動画／ゲーム | -4 | 光と覚醒刺激でメラトニン分泌が遅れる |
| 遅い食事・夜食・食べすぎ | -3 | 消化活動と胃食道逆流で睡眠が浅くなる |
| 長い昼寝（夕方以降・30分超） | -2 | 睡眠圧が下がり夜の入眠が遅れる |
| 強いストレス・喧嘩・泣いた・不安 | -5 | 過覚醒。入眠困難と悪夢の主因 |
| 運動（日中〜夕方） | +3 | 深睡眠が増える。寝る直前の激しい運動は逆効果 |
| 日光・外出 | +2 | 体内時計が整う |
| 入浴（寝る1〜2時間前の湯船） | +2 | 深部体温の下降で入眠しやすくなる |
| 日記の気分（1〜5） | (気分-3)×2 | 気分の落ち込みは睡眠の質低下と双方向に関係 |

## 6. 寝る前のアドバイスの原則

- **1回に1〜3個**。多すぎると実行されない。優先順位: 悪夢 > 金縛り > 中途覚醒 > 寝つき > アルコール > 短時間睡眠 > 目覚めのだるさ > 画面 > カフェイン > ストレス > その他。
- **行動レベルで具体的に**（「早く寝ましょう」ではなく「今夜は30分早く布団に入る」）。
- **今夜できることだけ**。
- 根拠のある方法を優先する:
  - **イメージ・リハーサル療法（IRT）**: 繰り返す悪夢を昼間に思い出し、結末を書き換えて数分イメージする。悪夢の頻度を減らす効果が確認されている。
  - **刺激制御法**: 眠れないまま20分経ったら一度布団を出る。布団＝眠る場所という結びつきを守る。
  - **起床時刻の固定**: 就寝時刻より起床時刻の固定のほうが効く。
  - **朝の光**: 起床後30分以内に10分以上。体内時計をリセットする。
  - **画面オフ**: 寝る1時間前。
  - **カフェインは14時まで、アルコールは寝る3時間前まで**。
  - **寝室環境**: 暗く・静かに・少し涼しく（18〜20℃目安）。
  - **呼吸法（4-7-8）や漸進的筋弛緩**: 寝つきに。
  - **ワーリータイム／明日のToDoを紙に3つ**: 頭が回って眠れないときに。
  - **睡眠麻痺**: 横向きで寝る、睡眠時間と時刻を規則的に。恐怖時は「指先を動かす」ことに集中すると解ける。

## 7. 相談を勧めるべきサイン（レベルに関係なく）

- 悪夢や不眠が **2週間以上** 続き、日中の生活に支障がある
- 眠るのが怖い、寝るのを避けている
- 大きないびき・呼吸が止まると言われる（睡眠時無呼吸の疑い）
- 日中に突然眠り込む、笑ったときに力が抜ける（ナルコレプシーの疑い）
- 夢の内容を実際に体が演じてしまう（叫ぶ・殴る）（REM 睡眠行動障害の疑い）
- 薬を始めた／やめたあとから悪夢が急増した

これらは睡眠外来・心療内科での相談を、やさしく勧める。

## 8. データとして蓄積する項目（将来の AI 学習・分析のため）

夢の記録1件につき、次を `sleep` フィールドに保存する。

```json
{
  "score": 62,
  "level": 3,
  "factors": ["wakeups_once", "caffeine"],
  "check": { "onset": "normal", "wakeups": "once", "feel": "normal" },
  "hours": 6.5,
  "diaryDate": "2026-09-13",
  "at": "2026-09-14T07:12:00.000Z"
}
```

- `factors` は本文書 2〜5 章の要因 ID。
- 日記（前日）は `diary` コレクションに日付キーで保存し、夢の分析時に `diaryDate` で結びつける。
- AI で分析するときは、この JSON と夢の本文・前日の日記本文を渡し、本文書を system prompt にして「score / level / factors / advice」を構造化出力させる（`POST /api/sleep`）。
