# 月あかりの仲間たち — キャラクター設定集

ユメタンの夜空を旅する16体の夢の仲間。夢の記録をそっと見守る存在として、内蔵の画像生成ツールで1体ずつ制作しました。名前・役割・物語・ひとことは、日本語・韓国語・簡体字中国語・英語で用意しています。

## 共通のデザイン

- 柔らかなぬいぐるみ・フェルトの質感、丸いシルエット、月と星の金細工。
- 深いインディゴの背景。背景込みの正方形画像で、透過PNGではありません。原本は1254×1254px、配信用WebPは768×768px。
- グループ色はローズ（悪夢）、藤色（予知）、ミント（明晰）、琥珀（反復）。
- 怖い出来事の再現ではなく、その夢に寄り添う役割で個性を表現。キャラクターの性格は創作で、ユーザー本人の性格や健康を断定しません。
- 基本画像は各1枚、計16枚。睡眠レベル1〜5はアプリ上の星と光で表現し、未測定時は星を表示しません。5段階の別イラストは含みません。

## 更新方法

4言語の設定は `public/assets/characters/moonkeepers-v1/catalog.js` が正本です。画像を更新するときはバージョン付きフォルダを新設して原本を保存し、表示参照とService Workerのキャッシュも更新してください。現在の配信用画像は `npm run characters:build` で原本から再生成できます。処理は縮小とWebP変換だけで、構図の切り抜きや加筆はしていません。
