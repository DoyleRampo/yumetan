# 今後用意してほしいもの（素材・情報）

v4.0.0（16タイプ・睡眠の質・多言語・日記・アラーム）で、コード側は動く状態まで作りました。
以下は **チームで用意していただくと、そのまま差し替えるだけで反映される** ものです。

## 1. 16タイプのキャラクター画像（最優先）

添付いただいた一覧画像（4×4）を **1枚ずつ切り出して** 次のファイル名で `public/types/` に置いてください。
置いたら自動で使われます（無いあいだは `public/types/NN.svg` のプレースホルダーが表示されます）。

| ファイル | タイプ | | ファイル | タイプ |
|---|---|---|---|---|
| `01.png` | ① 追跡系 | | `09.png` | ⑨ 明晰夢系 |
| `02.png` | ② 喪失系 | | `10.png` | ⑩ 部分自覚系 |
| `03.png` | ③ 拘束系 | | `11.png` | ⑪ 観察者系 |
| `04.png` | ④ 崩壊系 | | `12.png` | ⑫ 挑戦系 |
| `05.png` | ⑤ 未来暗示系 | | `13.png` | ⑬ 場所固定系 |
| `06.png` | ⑥ 直感警告系 | | `14.png` | ⑭ 人物固定系 |
| `07.png` | ⑦ 象徴解釈系 | | `15.png` | ⑮ 展開固定系 |
| `08.png` | ⑧ デジャヴ系 | | `16.png` | ⑯ 感情固定系 |

- 推奨: **正方形 800×800px 以上、PNG または JPG（JPG の場合は拡張子 `.png` のままでも表示されますが、できれば PNG）**。
- 画像の中に文字（タイプ名・説明）は **入れない** でください。名前・説明はアプリ側が4言語で表示します（添付一覧の文字入りでも一時的には使えます）。
- できれば **レベル別の差分（Lv.1〜5 で表情や背景が少しずつ明るくなる）** があると「育てる」感が出ます。ファイル名は `03_lv1.png` … `03_lv5.png` を想定（あれば対応します）。
- 広告用に、16タイプ一覧の **1枚絵（1080×1080 / 1080×1920）** も別途あると便利です。

## 2. アプリアイコン・スプラッシュの差し替え（任意）

16タイプを前面に出す方針なら、`assets/icon.png`（1024×1024）と `assets/splash.png`（2732×2732）を差し替えて `npm run mobile:assets`。

## 3. 睡眠の質の「ルール」の確定

`knowledge/sleep_quality.md` に、研究ベースの配点（悪夢 -12、金縛り -10、寝つき悪い -12 …）をまとめ、`public/engine/sleep.js` に同じ数値を入れてあります。
方針が決まったら **この md の表の数字を書き換えてください**。エンジン側の数値（`sleep.js` の `CHECK` / `HOURS` / `dreamFactors` / `DIARY_FACTORS`）も合わせて直します。AI 化するときは md がそのまま system prompt になります。

## 4. 16タイプの文章（コピー）の監修

`public/engine/types.js` に、各タイプの「名前 / 一言 / 説明 / キャラ紹介 / 傾向」を **4言語（日・英・韓・中）** で入れてあります。
ネイティブチェックや、広告のトーンに合わせた言い換えがあれば、このファイルの該当文字列を直してください。

## 5. アンケート（16問）の確定

チームメンバーの `yumenote_v3.html` の16問を参考に、1問=1タイプで作りました（`types.js` の `QUIZ`）。
質問文を変えたい場合はここを直せば、4言語分もここにあります。

## 6. 翻訳の監修

UI の全文言は `public/i18n.js` に4言語で入っています。韓国語・中国語は機械的に訳したレベルなので、ネイティブの確認があると安心です。

## 7. AI 機能に必要なもの

- Claude API キー（サーバーの `ANTHROPIC_API_KEY`）。**利用者が自分のキーを「設定 → 詳細設定」で入れても使えます**（その人はサーバーの回数制限の対象外）。
- AI を有効にすると使えるもの: 夢の読み取り（4言語対応）、手書きノートの写真の文字起こし（`/api/ocr`）、睡眠の質の判定（`/api/sleep`）、16タイプ診断の再判定（`/api/type`）、質問形式（4言語）。

## 8. アプリストア関連（アラーム・通知）

- Android: 追加のストア申請項目はありません（`SET_ALARM` は通常権限）。
- iOS: アプリから時計アプリのアラームを直接作る公開 API はありません。「時計アプリを開く」+「アプリの通知（毎日の起床通知）」で対応しています。通知の許可文言はこれで問題ないか確認してください。

## 9. 手書きノートの認識（AI）

現状は「写真を添付 → AI が有効なら文字起こし」です。AI を使わない場合は、写真を記録に添付しつつ本文は手入力です。
将来、端末内 OCR（Google ML Kit / Apple Vision）に切り替える場合は Capacitor プラグインの追加が必要です。
